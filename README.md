# FitBuddy - AI Fitness Coach
AI-powered fitness app using Google Gemini.

## Milestone 1 - Model Selection
- Tested: T5, BART, DistilBERT, Bloom
- Final: Gemini 1.5 Pro (7-day workout plans) + Gemini Flash (nutrition tips)

## Architecture
- Frontend: HTML + Jinja2
- Backend: FastAPI
- AI: Gemini API
- DB: SQLite + SQLAlchemy
